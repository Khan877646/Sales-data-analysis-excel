# Sales Data Analysis Using Excel

## About the Project

This is my second Business Analytics project, where I worked with a sales dataset and used Microsoft Excel to analyse the data.

The main aim of this project was to understand the sales performance of different products and regions and to find useful patterns in the data. I started by organising the dataset and then used Excel formulas, Pivot Tables and charts to perform the analysis.

I also created a simple dashboard to bring the important results together in one place. This made it easier to look at the overall performance without going through the complete dataset every time.

## What I Worked On

- Organised and checked the sales data
- Used Excel formulas for calculations
- Created Pivot Tables for analysis
- Calculated important KPIs
- Analysed sales and profit
- Compared product performance
- Compared regional performance
- Looked at order trends
- Created charts and visualisations
- Built an Excel dashboard
- Identified key findings from the analysis

## Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts
- Excel Dashboard

While working on this project, I got more comfortable with using Excel for data analysis. I learned how to work with a larger dataset, use Pivot Tables to find useful information and present the results through charts and a dashboard.
